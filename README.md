# Career Builder

Career Builder is a full-stack web application that allows recruiters to create, customize, and publish branded career pages for their companies.

The platform provides recruiters with a dashboard to manage job openings and two different ways to build a careers page:

1. A structured section-based editor
2. A visual drag-and-drop canvas builder

Published career pages automatically display the company's active job openings.

---

# What I Built

The main goal of Career Builder is to make it easy for companies and recruiters to create their own careers page without building a separate website from scratch.

## Main Features

### 1. Recruiter Authentication

Recruiters can:

- Sign up using email and password
- Create their company workspace
- Log in securely
- Access protected recruiter pages
- Log out of the application

Authentication is handled using Supabase Auth.

---

### 2. Recruiter Dashboard

After login, recruiters are taken to a dashboard where they can view and manage their company workspace.

The dashboard provides:

- Active job count
- Careers page status
- Public careers page link
- Recent jobs
- Navigation to job management
- Navigation to careers page editors

---

### 3. Job Management

Recruiters can manage job openings from the Jobs section.

Supported operations include:

- Create a new job
- Edit an existing job
- Delete a job
- Activate or deactivate a job
- Manage job details

Each job can contain information such as:

- Job title
- Department
- Location
- Work policy
- Employment type
- Experience level
- Job type
- Salary range

Only active jobs are shown on public career pages.

---

### 4. Structured Careers Page Editor

Career Builder provides a simple section-based editor where recruiters can build their careers page using predefined sections.

Available sections include:

- Hero
- About
- Life at Company
- Statistics
- Benefits
- Company Values
- Testimonials
- Hiring Process
- FAQ
- Open Roles
- CTA Banner
- Footer

Recruiters can:

- Add sections
- Remove sections
- Reorder sections
- Edit content
- Show or hide sections
- Change colors
- Change fonts
- Upload branding images
- Preview the page
- Publish the page

The structured editor maintains separate draft and published versions.

This allows recruiters to make changes without immediately affecting the live careers page.

---

### 5. Visual Canvas Builder

The second editing option is a visual drag-and-drop builder powered by GrapesJS.

It gives recruiters more freedom over page design.

The canvas builder supports:

- Drag-and-drop editing
- Custom page layouts
- Editable text
- Custom styling
- Image support
- Company branding
- Responsive layouts
- Dynamic job listings

The editor saves GrapesJS project data as a draft.

When the recruiter publishes the page, the HTML and CSS generated by GrapesJS are stored as the published version.

---
